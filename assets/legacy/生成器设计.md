### spaceMap.json生成器

现在要求你，帮我写一个python脚本，用于生成spaceMap.json，要求使用argparse做可交互式参数，让用户控制输入。

你可以现在Python预制一个恒星-行星-卫星的名称列表，以供选用，填写key和"displayName"

"starType"读取starType.json根据规则随机生成。

"position"根据一下参数规则随机生成

```
--posrange 恒星系x，y坐标范围，默认为100（ly）

--minl 最小恒星系间距，默认为5

--count 生成的恒星系数量
```



"surface"预留，功能后续添加，先默认设置为{}

"planet"-"position"-"orbitalRadius"即行星轨道半径根据以下参数随机生成

```
--mino 最小行星轨道，默认为0.5（au）

--maxo 最大行星轨道，默认为10（au）

--ro 随机生成选项，可选均匀分布，正态分布

--roe 随机生成数的数学期望，默认为5

--ros 随机生成数的标准差，默认为100
```

行星的数量根据一下规则生成

```
--minc 最小行星数量，默认为1

--maxc 最大行星数量，默认为8

--rc 随机生成选项，可选均匀分布，正态分布

--rce 随机生成数的数学期望，默认为6

--rcs 随机生成数的标准差，默认为1
```

"planet"-"planet"-"position"-"orbitalRadius"即卫星轨道半径，要限制卫星的轨道半径，不能让他与其行星相邻的行星相撞，在限制范围内使用均匀分布

```
--gaps 与其行星相邻的行星的最小间距
```

"radius"仅需根据下列规则随机生成即可，阶段
```
--minr 最小行星半径，默认为1000

--maxr 最大行星半径，默认为10000

--rr 随机生成选项，可选均匀分布，正态分布

--rre 随机生成数的数学期望，默认为5000

--rrs 随机生成数的标准差，默认为100
```

"planetType"根据planetType.json.json随机选择。
