# 功能模块边界

- `space-map`：宇宙连续视图、天体图形、视口控制、星图内容适配。
- `surface`：地表 React Flow 画布、设备节点、资源点与物流连线。
- `overview`：左侧资产/对象列表。
- `inspection`：右侧对象信息与操作详情。
- `settings`：设置、占位模块与存档重置入口。
- `action-bar`：底部建造栏，以及未来由能力和目标驱动的操作注册表。
- `fleet`：飞船/空间站运行时模型、移动算法与命令总线；不依赖 React。

共享图标、颜色、字号、缩放范围和交互参数分别位于 `shared` 与 `config`。领域数据解析继续位于 `domain`，跨场景应用状态位于 `state`。
